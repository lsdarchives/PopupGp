# Phase 5 Handoff

## Goal

Build the RSVP and polish layer on top of the completed user map flow.

## What Phase 5 Should Contain

- RSVP / ticket purchase flow from event detail
- Saved events or attended events view
- Profile editing and user preferences
- Search, filters, and discovery polish
- Event image and card cleanup
- Any remaining edge-case fixes in the user flow

## Starting Point

- Branch from `feature/phase-4-user-map`
- Keep the current map flow intact
- Reuse the event detail screen as the entry point for RSVP and purchase

## Exit Criteria

- User can find an event, open it, and RSVP or start purchase cleanly
- Profile and discovery screens feel consistent with the map flow
- Mobile build still passes the TypeScript check
- Phase 4 behavior remains unchanged
